## What This Is

Password manager and secrets vault — encrypted storage, sharing controls, audit logging, and self-hosted deployment with Docker.

Built for operators who want a self-hosted, Docker-deployed solution they control.

## Quick Start

### pip

```bash
pip install aegispass
```

### Docker (recommended)

```bash
git clone https://github.com/OneByJorah/AegisPass.git
cd AegisPass
docker compose up -d
```

### From Source

```bash
git clone https://github.com/OneByJorah/AegisPass.git
cd AegisPass
pip install -r requirements.txt
python3 app.py
```

## Features

- **Self-hosted** — no cloud dependencies, run on your own hardware
- **Docker Compose** — full stack deployment with one command
- **pip package** — install via PyPI
- **Dark theme** — operational, clean UI

- **Encrypted vault** — AES-256 encrypted password and secret storage
- **Sharing controls** — secure sharing with groups and permissions
- **Audit logging** — track all access and modifications
- **Self-hosted** — run entirely on your own infrastructure
- **Docker Compose deployment** — full stack with one command
- **Dark theme** — security-focused, minimal UI

## Tech Stack

- **Backend** — Python 3.11+, pydantic, pyyaml
- **Deployment** — Docker Compose, pip install
- **Configuration** — environment variables, config files
