# Screenshots

Only sanitized screenshots are stored here. Do not commit screenshots that show individual user names, email addresses, hostnames, IP addresses, or credentials.

## Safe screenshots to include

- `login.png` — login page + Services status panel (aggregate live stats only).
- `dashboard.png` — hero, KPIs, services status, device fleet status (aggregate counts only).

## Never include

- User directory tables
- Group member lists
- Audit log entries with real actor names
- Any page showing hostnames, IPs, or email addresses
